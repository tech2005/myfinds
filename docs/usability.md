
# MyFinds – Usability Testing Report

## 1. Objective

The objective of this usability testing was to evaluate how easily first-time users can navigate the MyFinds application, report a lost item, and understand the report status.

## 2. Participants

- Total participants: 3
- User type: First-time users
- Testing approach: Observational usability testing

## 3. Tasks Performed

Each participant was asked to:

1. Explore the MyFinds application.
2. Find and complete the Lost Item Report form.
3. Submit a lost item report.
4. Locate and understand the Status Page.

Participants were allowed to interact with the application independently without step-by-step guidance.

## 4. Usability Evaluation

The following areas were considered during testing:

- Navigation and page discovery
- Clarity of form labels and instructions
- Ease of completing the lost item report
- Report submission experience
- Discoverability and clarity of the Status Page

## 5. Key Areas for Improvement

The following areas should be reviewed based on participant feedback:

1. Improve the visibility of important navigation options.
2. Keep form labels and instructions simple and clear.
3. Provide clear confirmation after successful report submission.
4. Make report status information easy to locate and understand.
5. Ensure error messages explain how users can correct their input.

## 6. Overall Conclusion

Usability testing was conducted with three first-time users to evaluate the basic user journey of the MyFinds application.

The testing focused on the Lost Item Report and Status Page. The findings can help identify usability gaps and guide future improvements to the application's navigation, form experience, and status tracking.

## 7. Follow-up Actions

- Review participant feedback.
- Identify repeated usability problems.
- Prioritize improvements based on their impact.
- Conduct another usability test after implementing changes.
