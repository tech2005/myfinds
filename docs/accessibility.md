

# MyFinds – Accessibility Testing Report

## 1. Objective
To evaluate keyboard navigation, form accessibility, visible focus, and content readability across the MyFinds application.

## 2. Screens Tested

1. Landing Page / Reports Navigation – Passed
2. Login / Signup – Passed
3. Lost Item Report Form – Passed
4. Found Item Report Form – Passed
5. Report Status Page – Passed
6. Staff Dashboard / My Reports – Passed

## 3. Accessibility Checklist

| No. | Accessibility Check | Result |
|---|---|---|
| 1 | Keyboard navigation | Passed |
| 2 | Visible keyboard focus | Passed |
| 3 | Form labels | Passed |
| 4 | Required field identification | Passed |
| 5 | Form validation messages | Passed |
| 6 | Navigation links and buttons | Passed |
| 7 | Content readability | Passed |
| 8 | Keyboard accessibility of report actions | Passed |

## 4. Findings

No major accessibility issues were observed during the manual checks performed.

## 5. Conclusion

The tested screens were navigable using the keyboard, and the tested forms, labels, focus indicators, and report information were usable during the manual review.

Further automated accessibility checks and screen-reader testing are recommended.
